Deploying the Full Interactive Streamlit App

The repository contains both this fast static showcase (deployed on Vercel) and the complete dynamic Python application with real-time SHAP waterfall calculations, natural-language data querying, and live rainfall early warning simulator.

Streamlit Community Cloud (Recommended)

Deploy the stateful Python app with persistent WebSocket connections for 100% free with 1 click:

  1. Visit share.streamlit.io
  2. Click New app
  3. Select repository: leevanshi/landslide-susceptibility
  4. Main file path: app.py
  5. Click Deploy!

Run Locally with Full ML Acceleration

Run the full dashboard locally on your machine with access to interactive prompts:

cd landslide-susceptibility
pip install -r requirements.txt
