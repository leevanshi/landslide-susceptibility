Run the Dynamic Python Application

The full application in app.py contains real-time interactive SHAP waterfall calculations, a natural language query engine, and a live rainfall early warning scenario simulator.

☁️ Deploy to Streamlit Community Cloud (Free)
  1. Go to share.streamlit.io and connect your GitHub account.
  2. Click New app.
  3. Select repository: leevanshi/landslide-susceptibility
  4. Set main file path: app.py
  5. Click Deploy!
Launch Streamlit Community Cloud ↗
💻 Run Locally with Python 
git clone https://github.com/leevanshi/landslide-susceptibility.git
cd landslide-susceptibility
pip install -r requirements.txt
streamlit run app.py
